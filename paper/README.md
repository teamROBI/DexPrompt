# 논문 원고 안내

두 원고는 목적이 다르다.

| 원고 | 용도 |
| --- | --- |
| [dexprompt.tex](dexprompt.tex) | 실제 연구 정의·검증 범위를 반영한 작업 초안 |
| [성공 가정 PDF](hypothetical-success/dexprompt_success.pdf) | 모든 주장이 성립했다고 가정한 완성형 영문 논문. **수치는 집필용 가상 결과** |
| [성공 가정 Markdown](hypothetical-success/manuscript.md) | PDF와 같은 원고의 편집/검토 버전 |
| [성공 가정 원고 설명](hypothetical-success/README.md) | 그림·수치의 성격, 구성, 재생성 방법 |

현재 프로젝트의 실제 진척은 [PAPER_TODO](../PAPER_TODO.md)를 따른다.
성공 가정 원고의 완료형 문장·실험 규모·성능표를 실제 성과로 인용하지 않는다.
