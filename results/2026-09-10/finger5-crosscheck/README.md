# 손가락 5 초기값 실험 교차검토

2026-09-10. 사용자 첨부 보고와 finger5-flexion 산출물을 읽어 재검사했다.
최적화·정련·동적 파지·학습·student 평가를 새로 실행하지 않았다.

## 직접 확인한 내용

- 조건 40개가 중복 없이 존재한다. 음성 30개 중 2개는 범위 초과 미실행,
  실행 28개 정련 통과 0. 양성 10개 중 9개 통과.
- 저장된 원본 초기화 8개는 원본 파일과 byte 동일하고 원본 해시도 계획 기록과 같다.
- 저장 변형 30개는 qpos index 24 하나만 바뀌고 나머지 관절·루트는 동일하다.
  총 실행 입력 38개를 직접 읽어 링크 프레임 목표를 다시 계산했다.
  위치/법선 성분의 최대 절댓값 차이는 5.96e-8로 저장 검사 허용치 안이다.
- 종료 NPZ의 실제 contact_bodies와 판정을 다시 읽었다. 접촉군 수·정련 판정이
  results.json과 모두 일치한다. 음성 28개의 QP는 not_run, 양성은 QP 통과 9/탈락 1.
- 음성 손가락 5 간격 28행 모두 held=False. 최소는 2.186613 mm이며 기준 2mm를 넘는다.
- 기준선 재비교: 8개 모두 iter400 종료 자세 차이 0, 접촉 body와 판정도 동일하다.
  init4_original 대비 9c474332에서 접촉군 차이가 다시 확인된다.
- 관련 테스트 22개 통과. 기존 Dexonomy NumPy 변환 deprecation 경고 138개.
  이번 교차검토에서 전체 443개 테스트를 다시 돌린 것은 아니다.

실측: `audit.json`, `baseline.json`. 읽기 전용 검사 절차: `audit.py`.

## 해석과 다음 선택

"의미 있는 변화 없음"은 원래 접촉 집합·정련 통과가 개선되지 않았다는 뜻으로
한정한다. 손가락 간격은 일부 후보에서 1–2mm 이상 바뀌므로 최적화 상태가
완전히 둔감한 것은 아니다. 접촉 교대가 있는 후보 1개는 개별 접촉 변화 사례다.

이번 범위에서 같은 여섯 후보의 PIP 초기값 미세조정을 중단하는 판단은 타당하다.
2.187mm의 근접 실패를 통과로 세거나, 초기값 한 축의 실패를 물리적 불가능으로
확대하지 않는다. 양성 캔 QP 탈락은 현재 마찰·외력·잔차 기준의 필터 탈락이며
실제 접근·리프트 성공 여부는 시험하지 않았다.

다음 데이터 확보 축으로 파지 유형 변경은 타당하다. 새 유형의 정식 템플릿과
그 유형의 전체 요구 접촉군을 사용하고, 유형별로 동일한 반복 예산·장면·배치·
선택 규칙을 적용해야 한다. 이번 400회 결과와 비교하면서 새 유형만 기본값
50회로 돌리면 유형과 예산을 동시에 바꾸므로 직접 비교로 삼지 않는다.
파이프라인 기본값을 바꾸지 않고 비교 실험에서만 400회를 고정할 수 있다.

물체 변경도 장래 데이터 다양화 수단이다. 원인 분리 실험과 데이터 확보의 목적은
구분하며, 이 그릇·망치의 성공이 전체 연구를 진행할 필수 조건은 아니다.
Student 평가 및 다른 서버 이전은 사용자 지시대로 보류를 유지한다.
