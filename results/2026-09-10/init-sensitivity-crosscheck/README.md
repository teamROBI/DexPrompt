# 초기화 민감성 교차검토

2026-09-10. 저장된 40개 초기화와 기존 종료 결과를 읽어 대조했다.
새 정련·파지·학습·student 평가는 실행하지 않았다.

## 유지되는 결과

기존 결과 JSON의 40개 기록에서 음성 정련 0/30, 양성 9/10이며
`passed_every_filter`와 `refined_file_produced`의 합계도 각각 9개다.
이는 6개 음성 후보의 원본 6 + 루트 변형 24개에 대한 결과다.
원 보고서의 "음성 20개 변형"은 24개로 읽어야 한다.

손가락 5가 음성 30개 모두의 미충족 집합에 포함된다. 다만 접촉군 수가 3/4로
같다고 종료 자세·거리까지 완전히 둔감하다고 단정할 수는 없다.

## 수정한 검사 오류

`perturb_initialisation.write_variant`는 저장된 `hand_cpn_w` 대신 원래 링크 목표를
b2w→w2b로 왕복한 값만 비교했다. 따라서 저장 파일의 목표가 틀려도 통과할 수 있었다.

- 새 `check_saved_targets`는 파일을 다시 읽고, 저장된 `grasp_qpos`에서 저장된
  `hand_cpn_w`를 링크 프레임으로 변환한다. 비유한 값·shape 불일치·과도한 오차는 실패.
- 기존 40개 파일을 CPU 한 스레드로 재검사했다. 위치/법선 성분 전체의 최대 절댓값
  차이는 5.96e-8이다. 위치 오차는 따라서 0.06 µm 이하이며 법선 성분도 허용치 이하다.
  **기존 검사 오류는 확인됐지만 기존 파일의 목표 보존 위반은 발견되지 않았다.**
- 기존 `original` 8개는 qpos가 원본과 같지만 저장 접촉 목표는 원본과 bit 동일하지
  않았다. 불필요한 좌표 왕복과 float32 재저장 때문이다. 앞으로 무변형 기준선은
  원본 파일을 그대로 복사한다. 기존 산출물을 재작성하지 않았다.
- 고정 필드 검사도 저장 파일 기준으로 하며, 실패 시 예외를 낸다.
  기존 목적지 덮어쓰기는 거부한다.

실측은 `saved-targets.json`, 실행 코드는 `audit_saved_targets.py`에 남겼다.

## 비교 기준선 오류

접촉 상실 열은 이전 iteration sweep의 400회 실행을 기준으로 했다.
하지만 그릇 9c474332는 이번 `original`에서 손가락 3이 성립하고 이전 실행에서는
성립하지 않았다. 서로 다른 기준선을 쓰면 이번 변형이 잃은 접촉을 누락한다.
두 original 결과 차이가 반올림만의 영향인지 다른 차이가 있는지는 추가로 분리하지 않았다.

이번 실험의 후보별 `original` 기준으로 계산하면 접촉 상실은 **5개 변형**이다:

| 후보 | 변형 | original 대비 상실 손가락 |
| --- | --- | --- |
| 806273bc | tilt_minus | 1 |
| 806273bc | slide_plus | 1 |
| 9c474332 | tilt_plus | 3 |
| 9c474332 | slide_plus | 3 |
| 9c474332 | slide_minus | 1 |

`compare_current_original`을 추가했다. 현재 original이 없으면 실패하고, 관측 기록이
없으면 상실 없음이 아니라 미판정(None)으로 남긴다. 과거 400회 비교는 별도 필드로
유지한다. 재집계는 `results-current-baseline.json`, 과거 결과 JSON은 보존한다.
