# 실험과 작업 이력

- [실험 결과](experiments/): 날짜별 실험 보고·원시 집계. 성공과 실패를 함께 보존한다.
- [종료된 계획](plans/): 과거 작업 지시·인계·진행 문서. 재실행 지시가 아니다.
- `scratchpad/`: 초기 탐색 코드와 백업. 현재 실행 경로가 아니다.
- [최근 구조 변경 기록](maintenance/2026-09-13-layout/): 원본 snapshot·경로 대응·검증 결과.

현재 목표는 [RESEARCH_PLAN](../RESEARCH_PLAN.md), 진척은 [PAPER_TODO](../PAPER_TODO.md),
실행 상태는 [RESUME](../RESUME.md)를 읽는다. 과거 수치를 최신 상태로 덮어쓰지 않는다.
