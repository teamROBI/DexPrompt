## 유효한 핵심 결과

음성 후보 6개 중 5개에서 손가락 2의 held 판정이 50회 False → 400회 True로
바뀐다. 반복 예산 증가로 개별 접촉을 회복한 근거다. 음성 후보 전체 요구 접촉
통과는 여전히 0이므로 안정적인 파지나 새 물체 시범 확보로 확대 해석하지 않는다.

## 다음 실행 전에 보완할 점

1. 회복 5건의 실제 거리 범위는 **3.35–13.48 → 0.71–0.93 mm**다.
   원 보고서의 9.7–13.5 → 0.78–0.93은 그릇 9c474332의 회복을 범위에서 빠뜨렸다.
2. 남은 것은 손가락 5만이 아니다. 400회에서 그릇 806273bc의 손가락 2는
   5.06 mm, 9c474332의 손가락 3은 2.21 mm로 미달이다.
   손가락 5도 모든 후보에서 단조 수렴하지 않는다(498809d2는 200→400에 3.37→3.97 mm).
3. `GraspFilter.forward`의 순서는 limit → collision → contact → qp다.
   활성화된 앞선 검사는 통과했더라도 contact 탈락 뒤 QP는 실행되지 않는다.
   `bad QP error` 0건은 QP 통과 증거가 아니며, ADMM 내부 조기 종료와도 별개다.
4. 종료 상태의 침투 0과 관절 한계 여유는 상태 진단이다. 충돌 없는 연속 경로나
   모든 요구 접촉을 동시에 만들 수 있는 자유도가 존재한다는 증명이 아니다.
5. `tests/test_contact_scope.py`는 실제 `get_contacts`를 호출하지 않고 조건문을
   복제해 검사한다. 원 코드와 현재 규칙이 맞아도 원 함수의 퇴행을 탐지하지 못한다.
   실제 메서드를 호출하는 테스트로 바꾸고, 생성한 장면에 실제 world 접촉과
   hand-hand 접촉이 존재하는지 먼저 assert해야 한다. 빈 집합에 대한 통과를 피한다.
   body ID 범위 분류는 임의의 clutter에서 특정 목표 물체만 고르는 일반적 API도 아니다.
6. align seed는 템플릿과 접촉점 추첨도 바꾼다. 초기화만 바꾸려면 물체·유형뿐 아니라
   **템플릿 내용 해시, required_cbody, 접촉점 index/목표, 장면과 목적함수**를 고정하고
   초기 손 자세만 사전에 정한 방식으로 변화시켜야 한다.
   400회 고정 실험은 초기화 민감성을 확인할 수 있지만, 모두 실패한다고 예산 부족과
   물리적 도달 불가능을 분리하지는 못한다. 모든 필수 접촉의 동시 충족을 주 지표로 둔다.

다음 실험은 위 조건의 제한된 초기 손 자세 비교가 적절하다. 새 기본 반복 수나
접촉 임계값은 채택하지 않는다. 전체 요구 접촉을 만족하는 후보가 나올 때만
기존 접근→닫기→리프트 검증으로 연결한다.
