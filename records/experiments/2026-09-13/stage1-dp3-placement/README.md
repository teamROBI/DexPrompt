2026-09-13. **완료 (01:03:20 KST): 학습 조건 3/18, 미학습 배치 0/51.** 이전 3시범 모델과 Claude MLP 실험을 보존한다.

- 모든 원본은 teacher 성공으로 선별된 풀이다. 전체 후보 풀의 성공률이나 새 시범 생성 수율 추정으로 쓰지 않는다.
- 평가 입력의 형상·상태·요청 목표만 정책에 제공한다. 평가 행동과 feature 통계는 학습·정규화에 사용하지 않는다.

## 유지한 모델과 행동

이전 DP3 적응판의 관측·네트워크·action horizon·sampling을 유지한다.
현재 물체 visual mesh 512점 + 테이블128점, 상태125차원, 요청 Dexonomy root·squeeze 목표,
출력은 최종 actuator 명령27개이다. Mask·RGB·언어·teacher phase·시간은 입력하지 않는다.
중력 보상·접촉 피드백·IK를 학습 정책 실행에 추가하지 않는다.

학습 seed42, batch64, lr1e-4, warmup500/cosine, **20,000 updates** 후 최종 EMA checkpoint만 평가한다.
3시범 실험의6000회와 학습 예산도 다르므로 기존 결과와 단일 요인 비교를 주장하지 않는다.
학습 episode 균등 샘플링을 유지한다(물체별 수가 달라 물체 균등은 아니다).
정규화는 train_names 55개만 사용한다.

## 재생 상태 재사용 검사

- 기존 models/initial/arrays와 augment 파일의 SHA를 읽어 검증한다. 기존 패키지를 수정하지 않는다.
- 매 tick의 재생 q와 원본 right_state, time과 timestamp를 대조한다.
- 컴파일 mesh를 초기 물체 body 좌표로 옮긴 뒤, 각 행동 직전 object pose로 회전·이동한다. scale을 다시 적용하지 않는다.
- 직전 명령은 첫 tick의 보관 ctrl과 action[:-1]로 구성한다. 손 위치·회전과 qvel은 재생 상태를 사용한다.
- 72개 reset에서 온라인 관측과 비교하고, 이전 3시범의 실제 물리 재생으로 저장한 전체 tick 관측과 비교한다.
- 학습 전에 진단6개+평가17개 총23개 원본 명령을 같은 실행 경로에서 재생한다.
  모든 관절·신호가 정확히 같고 동일한 종료 판정을 통과해야 학습한다.

## 평가와 중단 규칙

- 학습 조건6개 × sampling seed1000/1001/1002 = 18회 먼저 평가한다.
- **완주0이면 미학습 배치 평가를 생략**하고 결과를 남긴다.
- 1회 이상 완주하면 고정한 미학습 배치17개 전부 × 같은seed3개 = 51회 평가한다.
  특정 물체의 학습 진단이 실패해도 평가 대상에서 그 물체를 빼지 않는다.
- 각 시범 원본 tick 길이까지 실행하고 마지막에 최소10cm·전체 필수 접촉군/힘을0.5초 유지해야 한다.
  중간에 잠깐 성공해도 종료하지 않으며, 품질 위반은 즉시 실패로 종료한다. 이전 DP3와 동일한 종료 규칙이다.
- 체크포인트 선택이나 평가 후 조정은 없다. 결과는 물체·배치·후보와 sampling seed별로 보존한다.
- 성공 rollout도 자동으로 student-ready나 VLA 학습용 인수 자료로 분류하지 않는다.
- 원본 명령 재생 시간과 정책 실행 시간을 별도 기록한다. 원본 재생은 후보 생성/IK 탐색 비용을 포함하지 않으므로
  이 비교에서 전체 VLA 시범 생성 효율이 좋아졌다고 주장하지 않는다.
