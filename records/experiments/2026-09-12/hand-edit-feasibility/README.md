## adapter (13:03, 구현 약 4분)

[collect_hand_edit.py](../../../../scripts/teacher/collect_hand_edit.py) — 기존 [손목 편집 wrapper](../../../../scripts/teacher/collect_wrist_edit.py)에
손 모양 편집을 더한 실행 범위 wrapper다. 공통 실행기·접촉 제어 코드는 수정하지 않았다.

- **DemoFunGrasp 규칙** (`tasks/grasp.py`): style 모드에서 손 관절 목표에 배율(scale)을 곱하고 관절별 잔차(delta)를
  더한 뒤 관절 한계로 clamp한다. 무작위 파지 자세에서는 delta를 더하고 접근 구간을 `q0 + (q − q0)·fraction`으로 보간한다.
- **HX5에 옮긴 부분**: 실행기가 닫힘 기준으로 쓰는 손가락 목표는 teacher의 `squeeze_qpos`(20관절)다. 손가락 그룹
  (digit)마다 다음과 같이 바꾼다.
  `squeeze'_d = open_d + scale_d · (squeeze_d − open_d) + delta_d`
  - 배율은 열린 자세 기준 비율이라 `scale = 1, delta = 0`이면 identity다(비트 단위 동일하게 건너뛴다).
  - 열린 자세(`open_qpos`)를 바꾸지 않으므로 접근 구간의 손 모양과 경로는 같다.
  - 관절 범위를 벗어나는 편집은 clamp하지 않고 **거부**한다(실행 전 계획 단계에서 8개 모두 범위 안 확인).
- **기존 접촉 피드백이 이를 쓰는 방식** (`ContactClosure`): 각 손가락은 `open + α·(squeeze' − open)`을 향해 닫힌다.
  α는 접촉 전에는 일정 속도로 늘고, 접촉 후에는 힘 오차(preload → hold force)로 조정되며, 침투가 목표를 넘으면 줄어든다.
  기하 보정 offset의 허용 범위도 `squeeze' ± residual`이다. 즉 편집은 **닫힘 방향과 크기**만 바꾸고, 실제로 얼마나
  닫을지는 여전히 접촉 피드백이 정한다. 고정 squeeze 목표 추종으로 대체하지 않았다. 압력 완화·guard·품질 판정은 그대로다.
- 검사 `tests/test_hand_edit.py` 5개 통과: 편집 0은 비트 단위 동일, 배율은 해당 손가락만 자기 방향으로, delta는 지정 관절만,
  범위 밖·잘못된 필드는 거부, 실행기가 같은 열린 자세에서 편집된 squeeze로 닫는다. 손목 편집 검사 5개도 함께 통과. Ruff 통과.
