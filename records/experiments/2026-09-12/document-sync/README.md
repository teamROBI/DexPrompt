## 바꾼 해석

1. 1번은 정확한 물체 형상·배치와 Dexonomy를 사용하는 **학습된 파지 선정·시범 적응·자동 생성**이다.
   기존 고정 후보 팔 접근 PPO를 이 전체 문제와 혼동하지 않는다.
2. 2번은 검증 시범을 사용하는 **물체 선택 조건부 시각 행동 BC**다.
   mask/point/language는 목표 선택 인터페이스이며 부위 지시·도구 사용은 선택적 확장이다.
3. Dexonomy 유형 선정/조건부 생성과 DemoFunGrasp one-step 편집 RL을 1번의 직접 참고로 명시했다.
   새로운 선정기/편집 RL이 이미 구현·학습된 것으로 쓰지 않았다.
4. mask·DINO는 DexGraspVLA 자체의 설계와 양립한다. 현재 구현의 사전학습 시각 특징과
   원본 전체 행동 모델 가중치 이식을 구분했다. From Grasps to Dexterity도 직접 선행연구로 넣었다.
5. teacher accepted, student 인수, 모델 학습, 폐루프 완주, 미지 형상 일반화를 각각 분리했다.
   A12 인수와 통합 검사 완료도 구분했다. 최신 원격 결과를 확인한 것처럼 상태를 갱신하지 않았다.
6. 기존 part API와 접촉 피드백은 보존했다. 실패 기록은 positive visual BC에 넣지 않지만
   1번 선정/적응 학습에는 필요한 감독정보라는 점을 데이터 가이드에 명시했다.

## 범위와 과거 기록 보존

기존 문서 **112개**를 수정했다: 루트6, configs4, plans9, results90, paper2, patches1.
이는 112개 모두를 새 결과로 다시 썼다는 뜻이 아니다.

- 루트 연구/진행/재개 문서와 논문 초안은 현재 두 단계 정의로 본문을 개정했다.

- 날짜별 계획9개는 현재 기준과 작업서로 연결하고, 당시 명령과 상태를 역사 기록으로 표시했다.
- 실험 보고90개는 현재 범위에 대한 해석 안내를 추가했다. 실험 수치와 판정 본문은 유지했다.
  삭제된 HANDOVER/NEXT_STEPS를 가리키던 링크3개만 현재 감사/재개/진행판으로 교체했다.
- 과거 PAPER_TODO·RESUME·ROADMAP은 [archive](../../../../plans/archive/2026-09-12)에 보존했다.
  상대 링크는 이동 위치에 맞췄다. 옛 P번호와 실행 지시는 현재 진행판보다 우선하지 않는다.
- 외부 third_party 논문/라이선스/README와 자산 문서, 코드·체크포인트·원시 결과는 개정 대상이 아니다.
