각 저장소의 실행 가능성이나 HX5용 공개 체크포인트 인수 완료를 뜻하지 않는다.

## 목표 구분

1. 정확한 시뮬레이터 형상·상태와 Dexonomy를 이용해 적합한 파지를 선정·조정하고,
   접근·닫기·리프트·유지를 검증한 시범을 자동 생산한다.
2. 이 시범으로 카메라와 물체 선택 지시(mask/point/language)를 받는 시각 행동 모델을 학습한다.
   부위 지시는 현재 필수 범위가 아니다.

## 1번의 구체적 우선순위

Dexonomy 본문 VI 및 부록은 이미 유형 조건부 생성 모델뿐 아니라 유형 분류기를 제시한다.
Classifier A는 원 데이터의 물체별 성공률로 유형 라벨을 만들고, B는 학습된 생성기가
생성한 파지의 유형별 성공률로 라벨을 만든다. 본문에서는 두 경로를 구분한다.
이것은 현재의 템플릿 정렬/정련 실행 경로와 다른, 학습된 유형 선정 경로다.

먼저 우리의 성공/실패 원장으로 학습 목표를 정의해야 한다. 생성 확률을 그대로
전체 실행 성공 확률로 취급하지 않는다. 물체 형상뿐 아니라 배치·로봇 상태·후보를
입력으로 사용하고, 접근·접촉 획득·유지의 단계별 결과를 보존하는 설계를 제안한다.
현재 적은 물체/편향된 후보 탐색 기록만으로 일반화 분류기가 학습됐다고 주장하지 않는다.

그 위에 DemoFunGrasp의 작은 시범 수정 행동을 결합하는 것이 우선 검토안이다.
논문의 one-step은 물리 시뮬레이션을 한 tick만 돌린다는 의미가 아니다.
정책이 수정값을 한 번 정하고 전체 수정 궤적을 실행한 결과로 학습한다.
Dexonomy와 HX5 성공 시범을 수정 기준으로 삼는 것은 논문 그대로가 아닌 우리 적응안이다.
원래 스타일/접촉 조건을 잃거나 실제 팔의 도달성을 위반하지 않는지 별도 검증해야 한다.
접촉 피드백을 고정 squeeze 추종으로 교체하는 것을 뜻하지 않는다.

ClutterDexGrasp의 목표/방해물 형상 관측은 이후 폐루프 실행의 참고로 둔다.
원 논문의 손–테이블 충돌 비활성화 및 침투 기반 종료 등 물리 조건은 우리 계약과
다르므로 보상·환경 설정을 통째로 복사하지 않는다. 현재 품질 기준 변경은 승인/실행하지 않았다.

## 앞선 설명의 정정

DexGraspVLA는 실제로 SAM/Cutie 목표 mask와 DINOv2 특징, 학습된 DiT 행동 제어기를 사용한다.
RGB·mask·DINO가 VLA와 별개인 선택이라고 설명한 것은 부정확했다.
현재 설계의 해당 요소는 원 논문 방향과 맞는다. 그렇다고 우리 자체 행동 모델이
원 논문의 사전학습 행동 가중치를 가져온 상태라는 뜻은 아니다.
원 논문은 36물체의 성공 시범2,094건으로 제어기를 학습한다. 우리12시범과 데이터
범위가 다르지만, 이것만으로 현재 단일 과제 BC 실패 원인이 데이터 부족이라고 확정하지 않는다.

## 권장 결합안 — 아직 구현/학습하지 않음

정확한 형상·배치 → Dexonomy 유형 선정/파지 후보 → 시범 적응 RL → 전체 물리 검증
→ 시각 시범 → DexGraspVLA 방식의 목표 조건부 시각 행동 모델.

목표는 RL 사용 자체가 아니라 자동 수집의 성공률·형상 범위·비용 개선이다.
먼저 후보 선정만으로 충분한지와 시범 수정이 추가 이득을 주는지를 분리해서 평가한다.
현재 고정 후보 접근 PPO의 실패를 이 전체 설계가 실패했다는 증거로 사용하지 않는다.
