# Teacher 수집과 시각 student 최종 통합

2026-09-11. 10시간 계획의 자동 실행이 끝난 뒤 원시 결과를 다시 확인했다.
결론: **HOPE teacher 시범 8건, 현재 student 계약까지 통과한 데이터 7건을 확보했다.
단일 병 x0 시각 정책의 전체 파지 전이는 최종 0/3으로 미달이다.**

## Teacher와 데이터

- 중앙: 세 물체 각각 1/12 성공, 합계 3/36. 성공 후보를 고정한 배치 확대는 5/12.
  두 비율은 조건이 다르므로 같은 모집단의 성공률로 합치지 않는다.
- 총 유효 실험 48조건에서 accepted 8건. 같은 후보 controller 재현 8건은 추가 시범이 아니다.
- HANDOFF의 8건에 대해 episode·모델·초기 상태·scene SHA를 다시 계산해 모두 일치했다.
  근거: `out/hope-handoff-hash-crosscheck.json`.
- **실행 비용 정정:** 디스크 부족으로 격리된 Raisins `attempts.json`에는 실제 episode ID가
  있는 4건이 추가로 남는다. 48은 최종 유효 시도 수이며, 총 물리 실행 기록은 적어도
  52건(+재현 8건)이다. 중단된 추가 부분 실행은 더 있을 수 있다. 이 네 건을 독립 실패로
  섞거나 없었던 계산으로 취급하지 말고 인프라 오류·재실행 비용으로 별도 보고해야 한다.
- 근접 한계 시범의 재현은 결정론적 반복 확인이다. 마찰·질량·센서 오차·실물 강건성 증명이 아니다.

3 teacher 후보, 2 파지 유형, 고유 초기 정책 입력 7개**. 재현 귀속과 시각 데이터,

## 시각 정책

원시 근거: `x0-results.json`, `x0-diagnosis.json`, `peaches-lecun-check.json`.
6,331 optimizer updates를 완료했고, 사전 지정 epoch 1/3/6/9/13 각각 완주 0/3이다.
최종 epoch 13이 주 결과이며 중간 checkpoint를 사후 선택하지 않았다.

최종 3회 모두 974 tick까지 실행됐으나 접촉 획득은 없었다. 최대 동시 필요 접촉군은
0/2, 1/2, 1/2이고, 최대 상승은 약 0, 1.00, 1.00 mm이다. 품질 위반이 없었다는 것과
파지가 성공했다는 것은 다르다. 충분히 들어 올린 뒤 hold만 실패한 상황도 아니다.

고정된 학습 관측에서 생성한 첫 행동의 최대 관절 오차는 frame 0에서
0.158–0.170 rad, frame 450에서 0.0026–0.0031 rad이다. 일부 관측의 근사는 좋아도
home부터 실행 가능한 경로를 배웠다는 근거는 아니다. 같은 tick 시범과의 오차만으로
실패 원인을 확정할 수 없으며 시간 진행 차이·폐루프 상태 분포를 함께 확인해야 한다.
HOPE 7건은 이 단일 병 학습에 사용되지 않았다. 이번 실패가 HOPE 데이터 실패는 아니다.

자동 후속 중 관측 진단은 완료했지만 명령 물리 재생 감사는 원격 사본의 스크립트 누락으로
실행되지 못했다. 이는 Codex 배포 누락이다. 스크립트만 보완해
lecun `dexprompt-x0-audit`, `out/x0-command-audit-recovery-v1`에서 CPU 감사 재개.
학습 모델·전처리·평가 기준은 바꾸지 않았다.

복구 감사 **완료**: `x0-command-audit.json`. 최종 세 실행의 저장 명령을 각각 974 tick
재생했으며 평가 대비 물리 신호 차이는 모두 0.0이다. 학습 소스 해시·재계산한 정규화가
일치했고 관절 순서·입력 전처리·명령 chunk 순서 검사를 통과했다. 시범의 pre-action
관절 상태 재현 차이는 0.0이다. 캐시 전체 해시를 이번 감사에서 다시 검사한 것은 아니다.
첫 명령 최대 관절 오차는 0.158–0.170 rad, 실행 중 최대 명령 변화는
0.227–0.471 rad/tick이다. 오차가 실패의 유일한 원인이라는 증명은 아니지만,
확인한 실행 경로에서 정책의 명령 실패가 그대로 재현됨을 확인했다.

## 다음 순서

1. 완료한 명령 재생 감사와 관측별 생성 오차를 근거로 폐루프가 처음 시범에서 벗어나는
   지점을 분석한다. 전체 코드에 오류가 없다는 선언으로 확대하지 않는다.
2. 승인된 7건을 불변 원본을 유지한 별도 진단 데이터 묶음으로 구성하고 lecun에 전송한다.
3. 단일 병 폐루프 실패 진단을 바탕으로 다음 단일 요인 실험을 정한다. 데이터 수만 늘리면
   현재 전이 문제가 자동으로 해결된다고 가정하지 않는다.
4. Teacher 쪽은 그릇·망치 미세조정을 재개하지 않는다. 이후 확대는 형상 다양성과
   품질 여유를 늘리는 방향으로 설계하고, 동일 후보 배치 증대를 후보 다양성으로 세지 않는다.

전체 논문의 계획용 진행도 추정은 기존 **약 35%(30–40%)**를 유지한다. 데이터 생성의
진전은 있지만 P5 시각 전체 실행, 목표 부위 변경, point/text 연결의 행동 검증,
새 형상·mild clutter·기여 비교·실물 결과는 아직 남아 있다.
