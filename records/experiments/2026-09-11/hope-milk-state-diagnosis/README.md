## 2. 보관 초기 상태에서의 4초 정지 관찰

**시간 기준 주의.** 보관 초기 상태는 실행기가 후보의 열린 손으로 reset 후 600 step(1.2 s) 안정화를 마친 **다음**
상태다. 여기서 t = 0은 이미 reset 후 1.2 s이고, 아래 "t = 1.2 s"는 reset 후 2.4 s다. 이것은 원래 실행의 시작 시점에서
**추가로 기다리는 진단**이며, 안정화 전부터 1.2 s를 기다린 원래 검사와 시간 기준이 다르다. 두 상태 모두 상태에
저장된 actuator 명령을 그대로 유지했다(관찰 중 명령 불변 확인).

같은 임계값을 **서술용으로만** 대입하면(판정 아님): 두 상태 모두 t = 1.2 s 한 시점에서는 선속도 ≤ 0.005·각속도 ≤ 0.05를
만족하지만, 마지막 0.5 s 최대값에서는 각속도가 0.05를 넘는다.

관찰:

- 두 실제 시작 상태 모두 물체가 **제자리에서 계속 작게 흔들린다**(4 s 동안 이동 0.06 mm, 회전 0.03° 미만인데 각속도
  최대 0.06–0.10 rad/s). 접촉점은 대부분 4개이지만 수시로 1개까지 줄어든다. 로봇은 물체에 닿아 있지 않다.
- 성공 PD 상태와 실패 LD 상태의 흔들림 크기는 비슷하다(RMS 거의 같음, 최대는 LD가 조금 큼). 이 진단만으로는 시작
  시점의 흔들림이 성공/실패를 가른다고 볼 근거가 없다(표본 2, 원인 분리 안 함).
- preflight(자체 brace, 기본 손 자세, reset부터)의 마지막 0.5 s 각속도 최대 0.098 rad/s와 같은 수준이다. 실제 시작
  상태에서도 지속 안정화 기준 밖이라는 원래 표기와 어긋나지 않는다.

## 원 preflight 조건과의 차이

| 항목 | preflight (원 `initial_gate_pass`/`sustained_stability_pass`의 근거) | 이번 진단 |
| --- | --- | --- |
| 모델 | 새로 컴파일한 B 모델(hook), B 자체 brace | 실제 실행의 보관 B 모델 |
| 손 자세 | Recorder 기본 자세 | 후보의 calibrated 열린 손 |
| 시작 시점 | reset 직후(안정화 전) | 실행기 1.2 s 안정화 후(보관 초기 상태) |
| 판정 | 1.2 s 판정 + 마지막 0.5 s | 추가로 기다린 4 s의 서술 지표(판정 아님) |

원래 `initial_gate_pass = true`, `sustained_stability_pass = false`는 **바꾸지 않았다**. 이번 결과는 별도 보충 자료다.
