# float32 행동 표현의 물리 재생 확인

2026-09-11. 학습 없이 같은 기록 명령을 두 정밀도 경로로 재생했다.
각 시범의 float64 원본과, float32 변환 → 해당 시범으로 적합한 정규화 → [-1,1] clip →
float32 역정규화 경로를 비교했다. 모델 출력 없이 oracle label만 사용하는 표현 가능성 검사다.
모든 실행은 기존 `contact_acquisition_guard_v2`를 그대로 사용했다.

| 시범 | float64 | float32 정규화 왕복 | 최대 명령 차이(rad) |
| --- | --- | --- | --- |
| 고정 병 teacher0002 | 974tick 완주 | 974tick 완주 | 1.19e-7 |
| 기존 캔 teacher0008 | 1251tick 완주 | 1251tick 완주 | 1.78e-7 |
| AlphabetSoup teacher0007 | 622tick 접근 변위 중단 | 같은 tick·사유 | 1.55e-7 |

이 세 사례의 성패 차이는 float64 시범/float32 정책 출력의 정밀도 차이로 설명되지 않는다.
물리 궤적이 비트 단위로 같다고 주장하지 않는다. 학습 오차나 다른 물체에 대한 견고성을
검증한 것도 아니다. AlphabetSoup은 앞서 확인한 접근/닫기 평가 계약 차이 때문에 양쪽 모두
중단되며, 그 결과를 float32 때문에 실패한 것으로 세지 않는다.

`check.py` / `result.json`. 3개 시범×2경로, 신규학습0, 모델 로딩0, 기준 변경0.
