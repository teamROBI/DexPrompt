# Milk 보관 초기 상태 진단 교차 확인

Claude의 `hope-milk-state-diagnosis` 보고서·스크립트·SUPPLEMENT·원시 NPZ를 대조했다.
추가 물리 실행은 하지 않았다. 수치 재집계는 `checks.json`에 있다.

- 원 HANDOFF 해시 불변, 성공 episode/model/initial state 해시 모두 일치.
- 기록된 물리 실행은3회. 성공 재생 기록은1099 tick, 최대 오차0·불리언 불일치0.
  이 재생은 Claude가 실행한 것으로, 이번 교차 검토에서 다시 실행한 것은 아니다.
- 두 NPZ 각각2000개의 선/각속도에서 첫0.5초·마지막0.5초·전체4초 최대/RMS를
  재계산한 값이 보고와 정확히 일치한다. 로봇–물체 접촉0, 테이블 접촉점1–4.
- 마지막0.5초 각속도 최대 PD0.0579965/LD0.0837391 rad/s, 전체 RMS는
  0.0239522/0.0236856 rad/s. 추가 대기에서도 지속 안정화 기준 밖이라는 관찰은 지지된다.

해석의 범위:

1. 보관 시점에서 추가로4초 기다린 진단이다. 원래 reset 직후부터의1.2초 검사로
   대체할 수 없으며 기존 gate 표시는 그대로 둔다.
2. 비교 LD 후보는 `no_validated_home_path`다. 닫기·유지까지 실행된 실패와 성공을
   대조한 실험이 아니므로, 시작 흔들림과 파지 성공/실패의 인과를 판단하지 않는다.
3. 보고된0.062mm는 시작–4초 끝 위치 차이다. 전 구간 최대 변위나 이동 거리로
   해석하지 않는다. 원시 NPZ에는 연속 위치·회전이 저장되어 있지 않다.
4. B 조건의 재현 가능한 teacher 성공1건은 유지한다. 학생 인수·기존A12시범 병합은
   여전히 하지 않는다. 현재 student 평가의 선행 조건으로 추가 Milk 튜닝을 요구하지 않는다.

Claude의 이번 한정 과제는 완료로 처리한다. 기존 low-noise student 평가와 A12 통합을 우선한다.
