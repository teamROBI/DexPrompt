# 첫 HOPE 중앙 시범 교차 확인

2026-09-11. AlphabetSoup / `10_Power_Disk` / 중앙 배치, yaw 추가회전0.

실제 중앙 실행 **12회 중1회 완주**. 첫 성공 `teacher_0007_yaw_000`은1192tick,
23.84초이며, 동일 후보 controller 재실행에서 episode SHA256이 완전히 같다.
이전 입력계약 거절12개는 물리 실행0회이며 이 분모에 섞지 않는다.

- Teacher 후보: `057c04e1d5755d4aa88bdc9cbe8bcebbc234b3d6c00da572cf8fc4bfd118f4bc`.
- 원본/재현 episode: `2ad2b2647274105e2ed08a4cb96b39986a798c073ff52ba8de287567d0a031a4`.
- 최대 상승11.81cm는 각 control tick 내 최소 높이의 최대값이다.
- 마지막1초는10.70–11.81cm, 필요한5개 접촉군을 모두 유지했다.
- 최대 물체 침투1.568mm(한계2mm), 최대 손가락 힘14.720N(한계30N).
- 테이블/방해물 침투0, 접근 중 물체 변위는 수치오차 수준이다.

`hold`라는 phase명에도 물체가 계속 상승한다. 성공은 **10cm 이상에서 요구 접촉을
종료 직전 연속 유지했다**는 현재 기준에 대한 판정이며, 정지 안정성·마찰 변화 견고성·
수학적 force-closure·실물 성공을 증명하지 않는다. 기존 캔과 같은 원통 계열이므로
새 HOPE 물체1개를 확보했다고 보고하며, 새 형상 계열 일반화로 세지 않는다.

[실측 신호 그래프](teacher-signals.png) · [PDF](teacher-signals.pdf) · [수치](signals.json).
그룹 힘은 매 tick 내부의 최소값, 침투는 최대값이다. 접촉은 시뮬레이션 신호이며
실제 tactile 센서 측정이 아니다. `plot.py`는 해시를 확인한 원본 NPZ에서 그래프를 만든다.

시각 student 데이터 변환/인수는 별도 진행 중이다. 이 teacher 성공을 student 성공으로
세거나, 아직 새 학습이 진행된 것으로 보고하지 않는다.

## 시각 인수 후 갱신

전체1192tick의 시각 재렌더는 측정 상태 불일치0, 물리 신호 최대차이0으로 완료했다.
목표 기억 reference는 head tick0, wrist tick387이며 온라인/오프라인 인과적 갱신이 일치한다.
양 카메라의 현재 목표 mask가 동시에 빈 tick은33개다. [RGB·mask 표본](visual-preview.png)을
확인했다. 접촉/phase는 그래프의 설명용으로만 읽었고 student 입력에 추가하지 않았다.

다만 student 평가기의 기록 명령 대조군이 close 중 접근 변위 검사에서 종료한다.
따라서 **teacher 시범은 유효하지만 student-ready 인수는 보류**한다.
[평가 계약 차이](../student-acquisition-contract/README.md)에 원인과 대조군을 기록했다.
