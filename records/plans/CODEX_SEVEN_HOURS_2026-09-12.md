## S0. 기존 실험의 판정부터 고정

[RESUME](../../RESUME.md)의 세 경로를 확인한다.

- `single-bottle-x0-low-noise-job-v1`: 학습·epoch별 평가·최종 진단.
- `low-noise-comparison-v1`: 기존 A와 low-noise B의 고정 최종 비교.
- `hope-twelve-job-v1/checks`: 데이터 통합·cache·DINO 검사·release.

`status.json`뿐 아니라 stage의 시작/종료, 결과 파일, 실제 PID를 확인한다.
epoch13과 seed1000–1002는 변경하지 않는다. 중간 최고checkpoint를 최종으로 채택하지 않는다.
완주/인계/최초 이탈/teacher 관측 오차를 구분하고 서로 다른 가중 loss 크기로 A/B를 판정하지 않는다.
기존 평가를 다시 돌려야 할 실제 누락/인프라 사유가 없으면 재실행하지 않는다.

원격 접속이 없으면 기존 로컬 자료로 계약/요약기 검사를 수행하고 결과는 미확인으로 유지한다.
접속을 반복 시도하며 한 시간을 전부 쓰지 않는다.

## S1. 새 clutter2건의 student 인수

입력은 `/data1/yspark/sim/icra/hope-clutter-v1/HANDOFF.json`의 Raisins 두 건뿐이다.
[읽기 전용 교차 검사](../experiments/2026-09-12/hope-clutter-crosscheck/README.md)에서
원본 모델/상태/episode/placement와 재현 episode 해시를 확인했다. 이는 시각 인수를 대체하지 않는다.

- 별도 인수 adapter로 target/distractor ID·배치·원본 source를 유지한다.
- 보관 모델/초기 상태 기반으로 시각 데이터를 준비한다. 새로 만든 단일 물체 모델로 대체하지 않는다.
- 원본의 모든 물리 신호와 pre-action state/action 정렬을 검증한다.
- target mask가 Raisins만 포함하는지 실제 segmentation/body 귀속으로 확인한다.
  방해물이 목표 참조 crop/요청 ID를 대체하는 오류를 막는다.
- 원본256해상도·기존 카메라 프로필·가시성/최초 유효 목표 기준을 유지한다.
- 기준 관측은 당시 보이는 정보로만 만들고 미래 관측을 과거 프레임에 주입하지 않는다.
- 기존 quality/intake 기준과 실제 모델 forward 검사를 통과한 것만 release한다.

두 건 모두 통과하면 **A12를 보존한 새14시범 묶음**을 준비할 수 있다.
하나만 통과하면13, 둘 다 보류면12를 유지한다. 숫자를 맞추기 위해 기준을 변경하지 않는다.
새 물체/새 teacher 후보가 늘어난 것으로 세지 않는다. Milk B는 포함하지 않는다.
독립 geometry validation이 없는 train-only 진단임을 표시한다.

대용량 출력은 `/data1`의 새 폴더에 둔다. 현 세션이 쓰기 권한을 갖지 못하면
공간이 확인된 workspace `out/`에 작은 준비 산출물만 만들고 bulk 생성/전송은 보류한다.
원본 MJB 복제를 최소화하고 전체 source 파일을 덮어쓰지 않는다.

## S2. 실제 시각 모델과 목표 사용 경로 확인

이번에 얻어야 하는 것은 '모델이 어떤 입력을 받고 있는지'의 명확한 증거다.

1. head/wrist RGB·visible mask·목표 기억·관절 상태·normalization·action chunk 계약을 검사한다.
2. 같은 장면에서 목표 mask/goal ID만 바꾸는 테스트와 reset 후 이전 목표가 남지 않는 테스트를 만든다.
   실제 관측 가능한 카메라별 목표 참조도 함께 바꾼다. mask만 바꾸고 이전 crop을 남기지 않는다.
3. 입력 경로 반응은 지시 이해/올바른 물체 파지의 증거가 아니다. 실제 행동 평가는 따로 표시한다.
4. Raisins 시범의 label을 그대로 두고 목표를 Peaches로 바꾼 잘못된 BC 학습쌍을 만들지 않는다.
5. 시뮬레이터 mesh·object world pose·teacher 목표·미래 contact/phase가 student 추론에 들어가지 않는지 검사한다.
6. 실제 DINO batch의 유한 출력과 checkpoint/dataset 불변을 검사한다. CPU 검사 비용을 측정해 불필요한 반복은 피한다.

새 목표 쌍의 teacher 정답이 없으면 지시 전환 실행 성공을 평가할 수 없다고 명시한다.
모델 출력이 달라졌다는 것만으로 semantic generalization을 주장하지 않는다.

## S3. 다음 단일 요인 실험

새 데이터를 늘리는 변경과 행동 모델을 바꾸는 변경을 동시에 비교하지 않는다.
먼저 S0의 실제 결과를 보고 아래 중 하나만 선택해 실험 계약을 고정한다.

- **기존 고정 과제에서 완주가 확인됨:** 현재 모델을 고정하고 데이터 확장 실험을 준비한다.
  작은 성공 과제와 A12/인수된 추가시범을 섞어 성능 향상을 이미 확인한 것처럼 쓰지 않는다.
  물체/배치별 평가를 고정하고 기존 성공 과제 보존도 평가한다.
- **최종 평가도 완주0, 기록 행동 대조군은 성공:** 같은 작은 데이터·동일 시각 입력에서
  기존 diffusion BC와 직접 action-chunk 회귀 BC를 비교할 수 있게 준비한다.
  이는 sampling/행동 생성 방식의 진단이다. encoder/목표 표현·정규화·chunk 길이·실행 prefix·
  joint limits·학습 예산·평가 장면/seed는 고정한다. 변경되는 모듈/파라미터 수를 공개한다.
  직접 회귀도 다봉 행동 분포를 평균낼 수 있으므로 만능 처방으로 간주하지 않는다.
- **최종 결과 미확인 또는 대조군/입력 계약 실패:** 학습 방향을 성공/실패로 결정하지 않는다.
  대안의 작은 호환 adapter·loss/입출력 테스트를 준비할 수 있지만 비교 채택/학습은 미정으로 남긴다.

기존 시각 모델은 그대로 보존하고 별도 config/모듈로 옵션을 구현한다.
기존 경로의 결과가 바뀌지 않음을 검사하고 preflight/forward/checkpoint load를 통과시킨다.
회귀 모델을 구현하더라도 아직 학습하지 않은 출력을 BC 성능으로 세지 않는다.
무학습 검사에서 backward/optimizer 호출이 없는지 확인한다.

이번 데이터는 작고 편향되어 있으므로 A12/14와 동일 형상에 대한 성공만으로 미지 물체 파지를 주장하지 않는다.
한 블록에서 여러 loss 계수, 여러 sampler, 여러 architecture를 연속 탐색하지 않는다.

## S4. 실행 연결과 평가 자동화

선택된 단일 비교에 대해 다음을 준비한다.

- lecun의 새 code/data/config/output 경로, 기존 작업과 충돌하지 않는 tmux 이름.
- 데이터/모델/초기 상태/정규화 해시, 고정 checkpoint·seed·계산 상한.
- 선행 gate 미통과 시 자동 종료. timeout/부분 결과를 완료나 성능0으로 치환하지 않는 상태 기록.
- 학습 완료 후 recorded/stationary 대조군과 정책 폐루프 평가를 연결하는 독립 실행서.
- 명시적으로 선택된 실험을 시작할 수 있는 명령, 시작 여부를 실제 optimizer 갱신으로 확인하는 기록.

계획을 작성하거나 tmux 명령을 준비한 것과 실제 학습 시작은 다르다.
원격 인증이 복구되지 않으면 전송/실행을 완료한 것처럼 보고하지 않는다.
학습은 lecun에서만 수행하고 다른 서버에서 우회 학습하지 않는다.
