# 연구 로드맵

연구 정의는 [RESEARCH_PLAN.md](../../RESEARCH_PLAN.md)를 따른다. 2026-09-12에 물체 선택 중심의
두 단계 학습으로 정리했다. [이전 로드맵](archive/2026-09-12/ROADMAP.md)은 역사 기록이다.

## 단계 A — 형상 기반 자동 시범 생성

정확한 형상·배치·로봇 상태 → Dexonomy 유형/후보 선정 → 시범 적응 → 전체 실행 검증.
학습된 선정기는 유형/후보별 실제 성공 가능성을, 적응 RL은 기존 시범에 필요한 수정을 배운다.
현재 템플릿 정렬·정련·실행 코드가 있다는 사실과 이 두 학습기가 검증됐다는 것은 다르다.

| 실험 | 고정할 것 | 완료 증거 |
| --- | --- | --- |
| 유형/후보 선정 | 형상 분할, 후보 풀, 실행 예산 | 비학습 순위 대비 미지 형상 실행 성공률·비용 |
| 시범 편집 RL | 원본 후보, 물리·접촉 계약 | 수정 없음 대비 전체 성공과 보존/변경된 접촉 |
| 형상·배치 확대 | 채택 규칙, 모든 실패 분모 | 여러 형상의 재현 가능한 학생 인수 시범 |

Dexonomy의 유형 분류/조건부 생성과 DemoFunGrasp식 편집 PPO가 주 참고다.
ClutterDexGrasp는 형상 관측·폐루프 teacher 학습의 참고다. 고정 후보 접근 PPO는 별도 기준선이다.

## 단계 B — 목표 조건부 시각 행동 학습

검증 시범 → DexGraspVLA 방식 BC → 카메라와 물체 선택 Mask/Point/Language로 팔·손 제어.
mask·DINO는 이 모델 계열의 원래 설계와 양립한다. 시각 특징 사전학습과 행동 사전학습을 구분한다.

| 실험 | 완료 증거 |
| --- | --- |
| 작은 과제 BC | home부터 동일 기준 파지·리프트·유지 |
| 목표 선택 반사실 비교 | 같은 장면에서 목표만 바꾸면 해당 물체를 각각 파지 |
| 형상 일반화 | 학습/선정에 쓰지 않은 mesh·형상 그룹에서 성공률 |
| 지시 입력 연결 | mask, 선택 point, language의 grounding와 실행 오류 분리 |
| 지식 전이 비교 | 동일 student/학습 예산에서 Dexonomy 선정·적응의 기여 |
| 실물 | 공개된 보정·실데이터 사용 조건으로 실제 로봇 평가 |

From Grasps to Dexterity의 계층형 목표 BC는 비교안이다. 목표 정답을 사용하는 진단을
최종 시각 정책 성공으로 집계하지 않는다. 부위/도구 사용은 확장이며 선행 조건이 아니다.

## 논문과 일정

논문의 가설은 학습된 선정·적응으로 생산한 Dexonomy 시범이 목표 조건부 파지의 데이터
효율·성공률·일반화를 개선한다는 것이다. 단순 모듈 결합을 새 기여라고 주장하지 않는다.
관련 선행연구와 감독정보·손 모델·평가 조건 차이를 공개한다. 현재 채택률 예측은 하지 않는다.
ICRA/IROS를 위한 embodied evidence를 목표로 하며 제출 연도·기한은 고정하지 않는다.

실행 상태와 단계별 TODO는 [PAPER_TODO.md](../../PAPER_TODO.md), 인계는 [현재 작업서](../../plans/CURRENT_WORK.md)를 따른다.
